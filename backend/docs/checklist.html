01
Nền tảng — Setup + Spring JPA + CRUD
~2 tuần 0/10 ▾
Setup Spring Boot project trên Spring Initializr: thêm Spring Web, Spring Data JPA, PostgreSQL Driver, Lombok, Validation
Spring
Viết docker-compose.yml: chạy PostgreSQL 16 local (port 5432, đặt POSTGRES_DB=ecommerce, thêm volume để data không mất khi restart)
DevOps
Chạy "docker-compose up -d", kết nối DBeaver vào localhost:5432, kiểm tra database ecommerce tạo thành công
DB
Cấu hình application.properties: datasource URL jdbc:postgresql://localhost:5432/ecommerce, PostgreSQL dialect, ddl-auto=update, show-sql=true
Spring
Tạo entity Category (id, name, description) + CategoryRepository extends JpaRepository
DB
Tạo entity Product (id, name, price, stock, description, @ManyToOne category) + ProductRepository
DB
Viết CRUD Category: Controller → Service → Repository (GET all, GET by id, POST, PUT, DELETE)
Spring
Viết CRUD Product tương tự, có thêm filter theo category
Spring
Exception handling: ResourceNotFoundException + GlobalExceptionHandler (@RestControllerAdvice) trả về JSON lỗi chuẩn
Spring
Test toàn bộ API trên Postman, export collection, push code lên GitHub, viết README cơ bản
Test
Postman gọi được API Product & Category, data lưu vào PostgreSQL, xem được trong DBeaver
02
Authentication — JWT + Spring Security
~2 tuần 0/8 ▾
Thêm dependency: spring-boot-starter-security + jjwt-api, jjwt-impl, jjwt-jackson (io.jsonwebtoken)
Auth
Tạo entity User (id, email, password, role: ADMIN/USER) + UserRepository
DB
API POST /auth/register → validate input → hash password bằng BCrypt → lưu DB
Auth
API POST /auth/login → kiểm tra email + password → tạo JWT token → trả về client
Auth
Viết JwtFilter (OncePerRequestFilter): đọc token từ header Authorization, validate, set SecurityContext
Auth
Cấu hình SecurityConfig: permit /auth/**, chặn các endpoint còn lại, disable CSRF, thêm JwtFilter vào chain
Auth
Phân quyền: chỉ ADMIN mới được POST/PUT/DELETE product & category — USER chỉ GET
Auth
Test Postman: không có token → 401, sai role → 403, đúng token ADMIN → 200
Test
Đăng ký → đăng nhập → lấy JWT token → gọi API protected thành công
03
Core Business — Cart, Order, Payment
~2 tuần 0/10 ▾
Tạo entity Cart + CartItem (cart @OneToOne với User, cartItem @ManyToOne Product, có quantity)
DB
API POST /cart/add → thêm product vào giỏ, nếu product đã có thì tăng quantity lên
Spring
API GET /cart → xem giỏ hàng + tổng tiền của user đang login (lấy user từ JWT)
Spring
API DELETE /cart/{itemId} → xóa 1 item khỏi giỏ hàng
Spring
Tạo entity Order + OrderItem + enum OrderStatus (PENDING, CONFIRMED, SHIPPING, DONE, CANCELLED)
DB
API POST /orders → tạo Order từ Cart → copy CartItem thành OrderItem → trừ stock → xóa Cart
Spring
API GET /orders → xem lịch sử đơn hàng của user đang login
Spring
API PATCH /orders/{id}/status → ADMIN cập nhật trạng thái đơn hàng
Spring
API POST /payment/mock → nhận orderId → cập nhật order status CONFIRMED → trả về payment success (không cần VNPay/Momo thật)
Spring
Edge case: đặt hàng khi stock = 0 → throw exception, trả về lỗi JSON rõ ràng, không tạo order
Test
Flow end-to-end: login → thêm giỏ → đặt hàng → mock payment → xem lịch sử đơn

DevOps

DevOps

Test

DevOps

DevOps

DevOps
Test toàn bộ API trên URL production bằng Postman, đảm bảo flow login → order chạy đúng
Test
Push code lên GitHub → Actions tự build + push Docker image → API live trên internet
